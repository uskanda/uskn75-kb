# uskn75-kb

分割型 JIS 75% + Cirque 35mm トラックパッド搭載キーボード — my dream keyboard

HHKB からの移行を目的に、**PCB から自製する分割型 JIS 75% キーボード**。
右半体に Cirque 35mm 円形トラックパッド、左半体にロータリーエンコーダ3個、
最下段の下に親指Enterを左右1個ずつ。
有線・QMK(Vial)・部品は原則国内調達。

### rev 1.8 で変えたこと（2026-09-10）

**U11（縦2u のステム位置）が確定し、キーキャップの現物待ちが PCB 発注のブロッカーから外れた。**
座標は1つも動いていないので PCB仕様 rev は 1.3 のまま。

| 変更 | 内容 |
|---|---|
| U11 | **現行値 `(173.831, 57.150)` のままで正しい**と確認。KiCad 公式 `SW_Cherry_MX_ISOEnter_PCB` / `_Plate`（Cherry MX カタログ由来）で、スイッチ中心が**縦2u の中心かつ下段 1.25u の中心**に来る |
| 根拠 | 決め手は**スタビ穴が Y ±11.90mm の対称配置**であること。ワイヤーが上下対称な以上、中心ステムは縦2u の中点にしか置けない |
| 位置づけ | ステム位置を決めているのは**プロファイルではなく MX + ISO の PCB 慣習**。Cherry / OEM / KAM / DSA のどれでも平面位置は動かない |
| §7 に追記 | 縦2u スタビの切り欠きは**スイッチ中心から Y ±11.90mm**。プレートマウントなので **PCB に穴は不要**、開けるのはプレート側 |
| 残リスク | 万一キャップが合わなければ**適合するものを別に探す**（ユーザー判断）。現物待ちで基板を止める損のほうが大きい |

### rev 1.7 で変えたこと（2026-09-06）

**現物確認で TM035035 に取付穴が存在しないことが分かり、パッドの吊り方（U9）が確定した。**
裏面にあるのは縁の切り欠き3か所と12時の小穴だけで、**表面側はオーバーレイが全面を覆っている**。
ネジがモジュールを貫通できないため、rev 1.6 まで書いていた「裏面から M2 スペーサーで吊る」は成立しない。

| 変更 | 内容 |
|---|---|
| 吊り方 | **プレート天面のリップ（内径 Ø33.0）で上から受け、下から受け座で押し上げる**。ネジはモジュールを貫通しない |
| 開口 | **PCB 側 Ø42（据え置き）と プレート側 Ø35.3 貫通 + リップ Ø33.0 に分離**。役割が違うので同じ数字で書かない |
| プレート材 | **非導電（PETG 自製 / アクリル）が必須**になった。リップがオーバーレイの外周を覆うため |
| 沈み込み（U4） | **リップの厚みそのもの**になった。0.5 / 1.0mm を刷り分けて実測する |
| キーキャップ | プロファイルを **行別 Cherry / OEM** で暫定確定。行6（親指Enter）は行5と同じ |

座標・外形・マトリクスは動いていないので **PCB仕様 rev は 1.3 のまま**。

### rev 1.5 で変えたこと（2026-09-02）

**狙いは、親指の定位置を Space から 無変換／変換 へ移すこと。** そのために次を同時に動かした
（1つだけでは成立しない。根拠は `pcb-spec.md` §11）。

| 変更 | 内容 |
|---|---|
| 親指Enter | 最下段の下に **1.5u を左右1個ずつ**新設。左は無変換の真下、右は変換の真下 |
| H の左の Enter | **廃止**。R4「Enter を押しやすく」は親指行が引き継ぐ |
| トラックパッド | その跡地へ移動。中心 (15.53, 101.44) → **(6.48, 76.20)**。ホーム行〜Z行を占有 |
| 左最下段 | Fn1 を左Ctrl の左へ。Ctrl 以降が 1.25u 右へ |
| 右最下段 | パッドが上がって空いた行を **2u 左へ**。矢印島も 0.8u 左へ（右Shift 1.75u に阻まれこれが上限） |
| 右内側列 | Ins / BS のさらに左に**無刻印2キー**を追加（割当は Vial で後決め） |
| マトリクス | 物理行0/1 が各10キーになり **6×9 → 6×10**。GPIO 左23→24 / 右22→23 |
| 基板外形 | 左右とも**親指Enterぶんが下へ張り出す段付き**。左 197.4×162.35 / 右 260.4×162.35 |

**受け入れた代償（`pcb-spec.md` §11 に記録）:**

- **最下段だけ JIS109 との位置互換を失う。** 英数ブロック・Z行・右Shift 1.75u は無傷なので R2 / R9 自体は維持
- **クリアランスの弱点が N から H へ移った。** N は 3.05 → 12.6mm に緩んだが、H が 3.05mm になった。
  H は**ホーム行**なので、自動マウス層の誤反応リスクは rev 1.4 より高い（**U6** で実測）

### D. 測定ではなく判断で決めるもの

- **U12（受け座の固定先）。** プレート裏へ M2 で留めるなら PCB に穴は要らない。**PCB へ留めるなら穴が要るので発注前に決める**
- **U14（縁リブの幾何）。** リップに縁リブを兼ねさせるか別に残すかを決め、決めたほうで H までの距離を計算し直す
- **コンデンサのフットプリント。** `pcb-spec.md` §6 の 0805 指定は変えない。買ったリード品は STEP 1 で使う

---

次にやること:

1. **U2③（全高の基準面）を実測する（最優先）。** 5.5mm がオーバーレイ面からの値か基板上面からの値かで、
   **受け座の高さ**——つまりパッド天面がプレート面のどこに来るか——が決まる
2. **U3 を現物合わせで決める。** FFC が着荷したので、基板側の FH12（下接点）／FH12A（上接点）を選べる。
   ここが決まると FPCコネクタのフットプリントが確定する
3. **STEP 1（パッド単体検証）に着手する。** モジュール裏面のテストパッドへ AWG30 で直結する。FFC と変換基板は要らない。
   **この案の山場（加速カーブとタップ判定）を基板より先に潰せる。** U13 も同じ場で見る
4. **キーキャップを棚卸しする。** 買った一式セットの中身を物理行ごとに数え、`procurement.md` §1 の行別内訳と突き合わせる。
   不足分と縦2u を通販で頼む
5. **通販ぶんを発注する。** 0805 コンデンサ・TRRSジャック・スタビ・キーキャップの不足分（`procurement.md` §5）。
   **PCB発注を待たせるのは TRRSジャックのフットプリント確認だけ**になった
6. **U10 と U8 を KiCad 上で確認する。** ソケットと MCU の実測値を入れてから干渉を見る
7. **U12 を決める。** 受け座の形を起こして KiCad と 3D で干渉を見る。**PCB へ留めるなら発注前に決着させる**
8. **キャップが届いたら U11 の答え合わせをする。** 現行値 `(173.831, 57.150)` と合うかを見る。合わなければ適合するキャップを別に探す
9. **U1 の残作業。** 同梱データシート／Mouser 掲載 v1.2 との突合。**回路図は転記済みの表で着手できる**

なお **基板外形と物理配置はもう少し詰める予定**（別途検討）。
`pcb-spec.md` §2 の外形と、そこから生成した座標データは**暫定として扱うこと**。

| 項目 | 左半体 | 右半体 |
|---|---|---|
| キー数 | 44 + エンコーダ3 | 54 |
| マトリクス | 6行 × 10列（COL8は押込専用 / COL9は未接続） | 6行 × 10列 |
| GPIO | 24 | 23 |
| MCU | Raspberry Pi Pico（スレーブ） | Waveshare RP2040-Plus（マスタ・USB-C） |

| 層構成 | 2層 / 1.6mm / HASL | 同左 |

- **ポインティング**: Cirque `TM035035-2024-002`（モジュール外径 Ø35.0mm・センサ有効径 Ø31.0mm）／ SPI 接続 ／

## 制作ステップ

0. **調達** — Mouser（済）+ 秋葉原・スイッチサイエンス（未）。キーキャップは**無刻印で確定済み**
1. **パッド単体検証** — Pico に繋いでマウスとして動かす。**加速カーブとタップ判定がこの案の山場**。基板を起こす前に納得する
2. **モック** — 開口位置と沈み込み（0.5 / 1.0mm）を Bambu Lab A1 で出力。**H に指を置いただけで誤反応しないか**を実測（U6。rev 1.5 で対象が N から H へ移った）
3. **右半体のみ試作** — JISキーコードと自動マウス層の検証はここで完結（左は既存 HHKB を併用して評価可能）
4. **左半体** — 通し検証 → ケース本番出力

**v1→v2 で2回発注する前提**で予算を見ること。概算 37,000〜66,000円。

## 触る前に読むこと

`pcb-spec.md` §9（未確定事項 U1〜U11）と §12（やってはいけないこと）。特に:

- **Cirque FPC 12ピンの信号順を推測で埋めない。** データシート必須。破壊に直結する
- **キーキャップを買う前にキー幅を確定しない。** 順序は「キャップ → PCB」
- **型番末尾は `-002` 厳守。** -003 は曲面、-001 は粘着で面一埋め込み不可
- **TRRS の活線挿抜厳禁。** VBUS(5V) が乗っている
- **3.3V を半体間で共有しない**
