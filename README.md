# uskn75-kb

分割型 JIS 75% + Cirque 35mm トラックパッド搭載キーボード — my dream keyboard

HHKB からの移行を目的に、**PCB から自製する分割型 JIS 75% キーボード**。
右半体に Cirque 35mm 円形トラックパッド、左半体にロータリーエンコーダ3個。
有線・QMK(Vial)・部品は原則国内調達。

## 仕様サマリ

| 項目 | 左半体 | 右半体 |
|---|---|---|
| キー数 | 43 + エンコーダ3 | 52 |
| マトリクス | 6行 × 9列（COL8は押込専用の疎な列） | 6行 × 9列 |
| GPIO | 23 | 22 |
| MCU | Raspberry Pi Pico（スレーブ） | Waveshare RP2040-Plus（マスタ・USB-C） |
| 基板外形 | 197.4 × 143.3 mm（矩形） | 266.6 × 158.0 mm（段付き） |
| 層構成 | 2層 / 1.6mm / HASL | 同左 |

- **ポインティング**: Cirque `TM035035-2024-002`（有効径35mm・フラットオーバーレイ）／ SPI 接続 ／
  右内側列 Enter の真下、中心 X=15.53 / Y=101.44 mm ／ 開口 Ø42mm ／ プレート面と面一
- **エンコーダ**: EC11互換 ×3、左端に縦1列（Y = 19.05 / 57.15 / 95.25、X = −17.15 mm）。
  回転は GPIO 直結、押込のみ新設 COL8(GP22) へ
- **半体間**: TRRS 4極（Tip=TX / Ring1=RX / Ring2=VBUS 5V / Sleeve=GND）、全二重、TX/RX クロス
- **ファーム**: QMK(Vial fork) / `MASTER_RIGHT` / `SERIAL_DRIVER = vendor` /
  `cirque_pinnacle_spi` / `POINTING_DEVICE_AUTO_MOUSE_ENABLE` / JIS は `INT1`〜`INT5`

詳細は `pcb-spec.md`、判断の根拠は `HANDOFF.md` §7。

## 制作ステップ

0. **調達** — Mouser（済）+ 秋葉原・スイッチサイエンス（未）。キーキャップ方針の確定
1. **パッド単体検証** — Pico に繋いでマウスとして動かす。**加速カーブとタップ判定がこの案の山場**。基板を起こす前に納得する
2. **モック** — 開口位置と沈み込み（0.5 / 1.0mm）を Bambu Lab A1 で出力。**N を打つ指が誤反応しないか**を実測
3. **右半体のみ試作** — JISキーコードと自動マウス層の検証はここで完結（左は既存 HHKB を併用して評価可能）
4. **左半体** — 通し検証 → ケース本番出力

**v1→v2 で2回発注する前提**で予算を見ること。概算 37,000〜66,000円。

## 触る前に読むこと

`HANDOFF.md` §8（未確定事項）と §9（やってはいけないこと）。特に:

- **Cirque FPC 12ピンの信号順を推測で埋めない。** データシート必須。破壊に直結する
- **キーキャップを買う前にキー幅を確定しない。** 順序は「キャップ → PCB」
- **型番末尾は `-002` 厳守。** -003 は曲面、-001 は粘着で面一埋め込み不可
- **TRRS の活線挿抜厳禁。** VBUS(5V) が乗っている
- **3.3V を半体間で共有しない**
